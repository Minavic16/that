# **App Name**: NestEdge Navigator

## Core Features:

- Interactive Map: Display an interactive map on the Contact page to show the location of the company's offices.
- Product Grid Layout: Design a grid-based layout for the Home page to showcase the two main products: NestEdge School Management Engine and NestEstate.
- Dynamic Property Filtering: Develop a dynamic filtering system on the NestEstate product page that allows users to search and sort property listings by location, price, and other criteria.
- AI-Powered Chatbot: Implement a chatbot tool powered by a large language model on the Contact page to answer frequently asked questions.

## Style Guidelines:

- Primary color: Indigo (#4B0082) to evoke trust and professionalism.
- Background color: Very light grey (#F0F0F0), nearly white, to ensure readability.
- Accent color: Lime Green (#32CD32) to draw attention to key actions.
- Font pairing: 'Poppins' (sans-serif) for headlines and short descriptions, 'PT Sans' (sans-serif) for body text.  Note: currently only Google Fonts are supported.
- Use Lucide icons throughout the website to maintain visual consistency.
- Apply a grid-based layout with a maximum content width of 1200px to ensure a clean and organized presentation across different screen sizes.
